# Slide Visuals

These SVG files are slide-ready visuals for the CS-593 presentation.

- `01_system_pipeline.svg`: current YOLO-to-tracking system plus remaining marker branch.
- `02_dataset_conditions.svg`: dataset counts, split, and conditions.
- `03_tracking_comparison.svg`: centroid vs SORT vs DeepSORT-lite baseline metrics.
- `04_detection_bottleneck.svg`: detection quality by scenario.
- `05_status_and_remaining_work.svg`: completed work, current analysis, and remaining marker work.

The tracking and detection metrics are baseline values from the current CSV outputs and should be refreshed if the final YOLO model is retrained and metrics are rerun.
